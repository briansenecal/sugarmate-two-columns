# Sugarmate Two Columns

A lightweight Chrome/Chromium extension that tweaks the Sugarmate app layout into a two-column presentation: the graph on the left and the insights/feed area on the right.

## What it does

- Replaces the default Sugarmate layout with a denser, two-column arrangement
- Expands key values and graph readouts for easier scanning
- Keeps the main graph and current reading visible while using wider browser windows more effectively
- Designed for the `https://app.sugarmate.io/*` app

## Installation

1. Download or clone this repository.
2. Open your Chrome or Chromium browser with extensions enabled.
3. Go to `chrome://extensions` (or `vivaldi://extensions` for Vivaldi).
4. Enable Developer mode.
5. Choose "Load unpacked" and select this project folder.
6. Refresh the Sugarmate app or reopen its window.

## Files

- `manifest.json` — extension manifest
- `layout.css` — styling override for the Sugarmate UI
